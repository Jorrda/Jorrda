**Full-stack & platform engineer · 2.5 years · three products taken from idea to production, and kept running there.**

I build complete software systems and own them in production: web and mobile apps, backend services, databases, cloud infrastructure, and the IoT devices that feed them. ### 🏆 What I bring

**🚀 End-to-end delivery.** From requirements and design documents to the UI, APIs, database, cloud deployment and production support. I built a complete logistics operations web app on my own, including enterprise single sign-on, and owned the platform layer of a food-quality IoT product.

**⚡ Performance.** I turn slow systems into fast ones and measure the result: production database queries cut from seconds to milliseconds, and heavy request patterns collapsed from hundreds of database calls into a handful.

**🛡️ Reliability.** I build the monitoring and alerting that tells a team when something breaks, and I close the gaps where data could be lost without anyone noticing: safe retries, failure queues, and alerts that reach the right people.

**☁️ Cloud and backend.** Serverless services and data pipelines on AWS, reactive backend APIs, CI/CD pipelines across development and production, and integrations with third-party platforms (Monday.com, Slack, BI dashboards, identity providers).

**📡 IoT and computer vision.** I deploy and maintain camera devices on customer production lines, with remote provisioning, automatic updates and remote recovery, and I built a motorized scanning rig with a hardware safety layer.

**🔐 Security and cost.** Access-control fixes, security audits, a full review of cloud permissions across multiple AWS accounts, and cost analyses that found and removed unused cloud resources.

**📱 Frontend and mobile.** Modern Angular apps, including three major framework upgrades, and a Flutter field-service app that prints labels directly to Bluetooth printers.

### 🛠️ How I work

- **Design first:** I write the spec and the plan, and have them reviewed, before the code
- **Evidence over guesswork:** every fix starts from a reproduced root cause and ends with a measured result
- **Ownership:** I ship it, monitor it, and fix it in production
- **AI-augmented, engineer-led:** Claude Code with custom skills and quality gates I built, and a security review on every change
- **Clear communication:** design documents, runbooks and reports written for both engineers and stakeholders
